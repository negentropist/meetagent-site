Dimensions / Trust

Checkability

Can you verify how it reached the answer?

Why it matters

Unverifiable answers have to be trusted or redone.

How to measure it

Check whether a person could reproduce a sample of results from what the agent shows.

Main threat to the measurement

An explanation can read well without being how the agent actually got the answer.

Levels

  • L1Answer only
  • L2Explains its reasoning in prose
  • L3Shows the code, query or sources
  • L4You can edit and re-run them
  • L5Full trace with intermediate results, plus version history or audit log
