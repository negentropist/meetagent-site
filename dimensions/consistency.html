Dimensions / Reliability

Consistency

Does the same task give the same quality of result every time?

Why it matters

One good demo tells you little about the next run.

How to measure it

Run each task at least three times in fresh sessions. Count tasks correct on every run.

Main threat to the measurement

Too few runs make an agent look steadier than it is.

Levels

  • L1Results swing between right and wrong on most tasks
  • L2Right on every run for a minority of tasks
  • L3Right on every run for about half of tasks
  • L4Right on every run for most tasks; differences are minor
  • L5Right on every run for nearly all tasks, and stable across versions
