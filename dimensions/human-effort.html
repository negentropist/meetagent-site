Dimensions / Autonomy

Human effort

How much help does it need to reach a correct result?

Why it matters

An agent that needs constant correction may save no time.

How to measure it

Use fixed correction prompts. Count corrections per task, and time spent reviewing.

Main threat to the measurement

An expert tester corrects faster than a typical user would, which understates the effort.

Levels

  • L1Must be steered at every step
  • L2Several corrections on most tasks
  • L3One or two corrections per task
  • L4Review only, with occasional correction
  • L5Runs unattended on a defined class of tasks; people handle exceptions
