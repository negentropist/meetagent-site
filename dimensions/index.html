Dimensions

What each dimension means, how to measure it, and how the measurement can mislead.

Task outcomes

Task successDoes it complete the task correctly?Output qualityCan you use the result as it is?

Reliability

ConsistencyDoes the same task give the same quality of result every time?RobustnessDoes it hold up when input is messy, ambiguous or hostile?Failing safelyWhen it can't do something, does it say so?

Autonomy

Human effortHow much help does it need to reach a correct result?Planning and tool useDoes it choose sensible steps and tools?

Trust

CheckabilityCan you verify how it reached the answer?Data handlingWhat happens to the data you give it?Permission limitsIs what it can do limited to what it should do?

Economics

Cost per completed taskWhat does a correct result really cost?SpeedHow long until you have a usable result?
