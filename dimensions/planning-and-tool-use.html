Dimensions / Autonomy

Planning and tool use

Does it choose sensible steps and tools?

Why it matters

Wasteful or looping work costs money and hides errors.

How to measure it

Read traces. Compare steps taken with an expert's path, and inject tool errors.

Main threat to the measurement

Rewarding a fixed path when another route is equally good.

Levels

  • L1Can't use tools usefully
  • L2Uses a tool when told to
  • L3Chooses tools itself, with wasted steps or loops
  • L4Plans multi-step work and recovers from tool errors
  • L5Close to an expert's path, and replans when the plan fails
