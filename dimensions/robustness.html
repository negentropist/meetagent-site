Dimensions / Reliability

Robustness

Does it hold up when input is messy, ambiguous or hostile?

Why it matters

Real work is rarely as clean as a demo.

How to measure it

Change wording, add errors to the data, leave out details and insert malicious instructions. Compare with clean-input results.

Main threat to the measurement

Testing only the variations the agent is known to handle.

Levels

  • L1Breaks on small wording or format changes
  • L2Handles rewording, fails on messy input
  • L3Handles common messiness, sometimes misreads ambiguity
  • L4Handles messy input and asks when a task is ambiguous
  • L5Results barely change under stress, and it resists malicious instructions in content
