Dimensions / Task outcomes

Task success

Does it complete the task correctly?

Why it matters

Nothing else counts if the result is wrong.

How to measure it

Run a representative set of tasks with known answers. Count fully correct first attempts.

Main threat to the measurement

Easy test tasks, or tasks the agent's builders have already seen, inflate the result.

Levels

  • L1Correct on under 50% of tasks
  • L2Correct on 50–70%, mostly simple tasks
  • L3Correct on 70–85%, including some hard tasks
  • L4Correct on 85–95%, including hard tasks
  • L5Above 95%, including hard and unfamiliar tasks
