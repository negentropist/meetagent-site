How we score

Each agent is scored 0 to 5 on six fixed dimensions, always in the same order, with bigger always better. We score the cheapest publicly priced plan that unlocks the agent's data features, and name it on the card. If the documentation doesn't say, the score is n/d (not disclosed) and the radar shows a gap, never a zero.

Scores reflect vendor documentation on the date shown, taken at face value. Hands-on testing with a fixed test pack is coming next and will be labelled "Tested". Nothing here is paid placement.
